## How to work

1. Read the lessons of a module in order (`NN-module/lessons/`).
2. After each lesson, do its exercises (`NN-module/exercises/`): edit the files marked `TODO`.
3. Grade yourself: `./tools/check.sh NN-module/exercises/NN-exercise` (Windows: `.\tools\check.ps1 …`).
4. When it's green, compare with `NN-module/solutions/` and read `NOTES.md`.
5. Take the module quiz (`quiz.md`).
6. Build the capstone milestone of the module and validate it: `./tools/check.sh capstone NN`.

A module is done when **all its checks are green** and its milestone is validated. Track it in [PROGRESS.md](PROGRESS.md).

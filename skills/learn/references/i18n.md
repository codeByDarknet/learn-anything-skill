# Language (i18n)

The course is written entirely in the learner's language, `lang`. The skill instructions are in English; the output is not.

## Determining `lang`

1. Explicit parameter `lang=<code or name>` (`lang=fr`, `lang=français`, `lang=pt-BR`, `lang=Japanese`) wins.
2. Otherwise, the language the user wrote the request in.
3. `/learn` alone with only a technology name (e.g. `/learn go`) and no other signal: use the language of the surrounding conversation; if none, English.
4. Store the normalized BCP 47 tag in `course.json.params.lang` and reuse it for every later subcommand.

## What gets translated

| Element | Language |
|---|---|
| Lessons, READMEs, SETUP, PROGRESS, quizzes, milestone specs, NOTES | `lang` |
| Code comments, TODO explanations, test failure messages, check script messages | `lang` |
| Your chat messages in tutor mode | `lang` (follow the learner if they switch) |
| Code identifiers, package/module names | Ecosystem convention (usually English) unless the learner asks for localized names |
| Folder keywords `lessons/ exercises/ solutions/ capstone/ milestones/ playground/ tools/ .learn/` | English (stable for tooling) |
| Slugs after numbers (`03-deployments`, `03-deploiements`) | `lang`, ASCII-transliterated, lowercase, hyphenated |
| Technical terms | Use the term practitioners actually use in that language; give the English term in parentheses at first use when it differs (e.g. « fermeture (closure) ») so the learner can search docs |
| Tool output, error messages quoted from tools | As the tool prints them (usually English) — then explain them in `lang` |

## Quality

- Write natively, not as a translation: idiomatic phrasing, correct typography (French non-breaking spaces before `: ; ? !` and « guillemets », Spanish `¿ ¡`, etc.).
- Right-to-left languages (Arabic, Hebrew, Persian): prose in RTL is fine in Markdown; keep code blocks LTR and avoid mixing directions within one line where possible.
- Keep numbering, links and anchors consistent after translation (anchors are generated from translated headings — link with explicit file paths rather than heading anchors when possible).
- Ensure all files are UTF-8.
